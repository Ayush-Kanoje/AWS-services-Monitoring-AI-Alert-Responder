# Architecture Diagrams

Place architecture diagram image files in this directory.

## Recommended formats

| Format | Use |
|--------|-----|
| `.png` / `.svg` | Exported from draw.io, Lucidchart, or Excalidraw |
| `.drawio` | Editable draw.io source file |

## Naming convention

```
aws-architecture-v1.png      ← full AWS service diagram
data-flow-simulate.png       ← incident trigger sequence
data-flow-history.png        ← history read flow
```

The `ArchitecturePlaceholder` component in the frontend is reserved for
embedding the primary diagram image once it is available.
