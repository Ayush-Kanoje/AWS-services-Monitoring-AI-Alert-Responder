# Screenshots

Place dashboard screenshots in this directory.

## Recommended captures

| Filename | Content |
|----------|---------|
| `dashboard-dark.png` | Full dashboard in dark mode |
| `dashboard-light.png` | Full dashboard in light mode |
| `simulation-trigger.png` | Simulation panel with a button highlighted |
| `ai-report.png` | Populated AI Incident Report panel |
| `incident-history.png` | Incident History table with rows |
| `architecture-overview.png` | Architecture pipeline section |

## How to capture

Use the browser's built-in screenshot tool or an extension like
[GoFullPage](https://chrome.google.com/webstore/detail/gofullpage) for full-page
captures at 1440 × 900 px.
